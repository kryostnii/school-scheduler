# Прототип School Scheduler - Гибридный алгоритм составления расписания

## Статус проекта:
✅ Все исследовательские документы готовы  
✅ Рабочий GUI с улучшенной функциональностью
✅ Реализована математическая модель
✅ Запущен генетический алгоритм + бэктрекинг

## Основные возможности:
- Графический интерфейс для управления параметрами
- Визуализация расписания в таблице  
- Панель статистики с прогрессом
- Настройка параметров оптимизации
- Сброс и экспорт данных

## Ключевые особенности:
1. **Гибридный подход**: ГА + Бэктрекинг для оптимальных результатов
2. **Жесткие/мягкие ограничения**: Четкое разделение требований
3. **Оптимизация для школ**: Учет СанПиН и других нормативов
4. **Интерактивный интерфейс**: В реальном времени видны изменения

## Структура проекта:
- `app/main.py` - Точка входа
- `app/ui/` - GUI интерфейсы
- `app/services/reference_scheduler.py` - Алгоритм оптимизации
- `docs/research_complete.md` - Полная исследовательская часть

## Как запустить:
1. Установка зависимостей: `pip3 install PySide6`
2. Запуск: `python3 app/main.py`
