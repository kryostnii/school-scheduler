# ВВЕДЕНИЕ

## Актуальность темы

Составление школьного расписания представляет собой сложную комбинаторную оптимизационную задачу, относящуюся к классу NP-трудных задач. Эта задача обладает множеством жестких ограничений (конфликты учителей, кабинетов, превышение лимитов уроков) и мягких требований ( СанПиН, окна между уроками, предпочтения преподавателей), которые необходимо учитывать при формировании оптимального расписания. 

Использование традиционных методов, таких как графовые алгоритмы раскраски, не позволяет эффективно учитывать все мягкие ограничения и сложные зависимости между элементами. Чистый генетический алгоритм может "застревать" в локальных оптимумах при наличии множества мягких ограничений. Поэтому необходимо применение гибридного подхода для достижения высокой эффективности и качества решения.

## Проблематика исследования

Одной из ключевых проблем при составлении расписаний является баланс между жесткими ограничениями (которые не могут быть нарушены) и мягкими требованиями для обеспечения качественного и удобного расписания. 

Существующие решения либо слишком упрощают задачу, либо не обеспечивают достаточной гибкости в учете различных условий. Настоящее исследование направлено на создание эффективного гибридного алгоритма для автоматического составления школьных расписаний с учетом комплекса жестких и мягких ограничений, включая требования СанПиН.

## Цель исследования

Целью данного исследования является разработка и реализация гибридного алгоритма (генетический алгоритм + бэктрекинг) для автоматического составления школьного расписания с учетом комплекса жестких и мягких ограничений, включая требования СанПиН.

## Задачи исследования

1. Формализация задачи составления школьного расписания как комбинаторной оптимизации
2. Разработка математической модели с четким разделением жестких и мягких ограничений
3. Реализация генетического алгоритма с учетом специфики задачи
4. Внедрение бэктрекинга для точечного устранения конфликтов
5. Проверка эффективности гибридного подхода на тестовых данных

## Структура работы

Данная работа состоит из введения, нескольких глав по исследованию и заключения. В первой главе представлены основные теоретические положения о задачах оптимизации и методах их решения. Во второй главе рассматриваются особенности задачи составления школьных расписаний. В третьей главе приведена реализация гибридного алгоритма. В четвертой главе дана экспериментальная часть с анализом результатов.
