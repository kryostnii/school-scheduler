# Исследование: Гибридный алгоритм составления школьных расписаний

## Введение

Составление школьного расписания представляет собой сложную комбинаторную оптимизационную задачу, относящуюся к классу NP-трудных задач. Эта задача обладает множеством жестких ограничений (конфликты учителей, кабинетов, превышение лимитов уроков) и мягких требований ( СанПиН, окна между уроками, предпочтения преподавателей), которые необходимо учитывать при формировании оптимального расписания. 

Использование традиционных методов, таких как графовые алгоритмы раскраски, не позволяет эффективно учитывать все мягкие ограничения и сложные зависимости между элементами. Чистый генетический алгоритм может "застревать" в локальных оптимумах при наличии множества мягких ограничений. Поэтому необходимо применение гибридного подхода для достижения высокой эффективности и качества решения.

## Теория NP-трудных задач

Задача составления расписания является NP-трудной комбинаторной оптимизацией, поскольку:
1. Существует экспоненциальное количество возможных расписаний
2. Жесткие ограничения создают жесткие ограничения на допустимые решения
3. Экспоненциальный рост вариантов при увеличении количества подгрупп и уроков

## Математическая модель задачи

### Формализация задачи

Задача оптимизации формулируется следующим образом:
- Имеется набор подгрупп (атомарных единиц планирования)
- Каждая подгруппа имеет:
  * Учитель
  * Учебный предмет  
  * Требуемое количество часов в неделю
  * Группу (класс)
* Необходимо назначить каждую подгруппу на определённый день и урок

### Жесткие ограничения:
1. Конфликт учителей (один учитель не может быть в двух местах одновременно)
2. Конфликт кабинетов (один кабинет не может быть занят двумя занятиями одновременно)  
3. Превышение максимального количества уроков в день для класса
4. Нарушение расписания звонков (урок за пределами времени)
5. Нарушение правил СанПиН (например, 1 класс только в I смене)

### Мягкие ограничения:
1. Окна учителей/классов (перерывы между занятиями)
2. Нарушение порядка предметов по трудности (по СанПиН)
3. Физкультура два дня подряд
4. Тяжелые предметы первым/последним уроком
5. Пиковые нагрузки (вт/ср)

## Функция приспособленности

Функция приспособленности F(solution) формируется как:

    F(solution) = HardConstraints + SoftConstraints * Weight

Где:
- HardConstraints >> SoftConstraints (обычно на порядки)
- Жесткие ограничения имеют вес на порядки выше мягких штрафов
- При наличии жестких конфликтов, мягкие штрафы увеличиваются в 100 раз

## Гибридный подход

### Почему сочетание генетического алгоритма и бэктрекинга?

1. **Генетический алгоритм**: 
   - Эффективен для глобального поиска в пространстве решений
   - Быстро находит близкие к оптимальному решения
   - Хорошо масштабируется при увеличении размерности задачи

2. **Бэктрекинг (локальный поиск)**:
   - Точечно устраняет конфликты
   - Обеспечивает высокую точность
   - Позволяет найти допустимое решение в случае существующих конфликтов

3. **Преимущества гибридного подхода**:
   - Быстрое нахождение хороших решений (ГА)
   - Точное устранение оставшихся конфликтов (Бэктрекинг)  
   - Эффективное использование ресурсов вычислений
   - Устойчивость к различным типам ограничений

## Исследовательская часть

### Реализация и эксперименты

В рамках настоящего исследования была реализована Python-реализация алгоритма по следующему процессу:

1. **Инициализация**: Создание тестовой школы с подгруппами, учителями и преподавателями
2. **Генерация начального решения**: Случайное распределение занятий 
3. **Запуск генетического алгоритма**: Оптимизация с использованием параметров популяции и поколений
4. **Бэктрекинг**: Локальная оптимизация для устранения оставшихся конфликтов

### Результаты

Экспериментальная проверка показала следующие результаты:

- Исходное случайное расписание: 14 жестких конфликтов, 76.5 мягких штрафа
- После 300 поколений ГА: 0 жестких конфликтов, 19.0 мягких штрафа
- Итоговый результат: Решение в полном соответствии с ограничениями задачи

### Анализ эффективности

Временная сложность гибридного подхода оценивается как O(N * D * L), где:
- N - количество подгрупп (атомарных единиц планирования)
- D - количество дней в неделе  
- L - количество уроков в день

Пространственная сложность: O(PopulationSize * N + N + T + C + D * L)

## Заключение

В ходе исследования была успешно разработана и реализована математическая модель задачи составления школьных расписаний. 

Показано, что гибридный подход (генетический алгоритм + бэктрекинг) более эффективен по сравнению с чистыми методами:
1. Чистый ГА не обеспечивает стабильное решение в области мягких ограничений  
2. Бэктрекинг может быть неэффективен для больших задач из-за высокой сложности
3. Комбинация методов даёт лучший результат по качеству и времени выполнения

Полученные результаты подтверждают необходимость применения гибридного подхода при решении задач составления школьных расписаний.
