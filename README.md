# School Scheduler — рабочий прототип

Десктопный прототип на Python: генетический алгоритм + локальное устранение конфликтов (бэктрекинг), графический интерфейс на PySide6 и импортируемые JSON-данные школы.

## Требования и запуск

- Python 3.11 или новее
- Установка зависимостей: `python -m pip install -r requirements.txt`
- Запуск из корня проекта: `python -m app.main`

На Linux требуется графическая сессия для Qt. Если в системе нет дисплея, можно проверить алгоритм и тесты без запуска GUI.

## Что работает

- Генетический алгоритм действительно выполняется на данных школы; вычисления идут в фоне, есть прогресс и остановка.
- Встроен пример школы, который можно заменить своими JSON-данными. Шаблон: [`examples/school_data.json`](examples/school_data.json).
- В приложении доступны кнопки «Открыть данные школы» и «Сохранить данные школы». JSON содержит классы, учебные группы, предметы, учителей (числовые ID), часы и необязательные кабинеты.
- Двойной щелчок по расписанию позволяет переместить урок; приложение пересчитывает фактические штрафы и предупреждает о росте жёстких конфликтов.
- Расписание можно сохранить и открыть как JSON, вместе с использованными данными школы. При открытии расписания встроенная школа загружается из файла.
- Светлая тема и цветовая маркировка предметов.
- Исследование сложности и NP-полноты опубликовано в [`docs/np_completeness_research.md`](docs/np_completeness_research.md).

## Формат данных школы

Скопируйте пример и укажите уникальные положительные ID классов/групп/учителей, номер параллели, предмет, часы в неделю и флаги `is_physical_education` / `is_heavy_subject`. `days_per_week` — число учебных дней от 1 до 7. Один объект `groups` — одна учебная группа с одним назначенным учителем; деление одного предмета на несколько одновременно проходящих подгрупп пока не поддерживается моделью алгоритма.

Пример файла содержит пояснённую структуру. Загрузчик проверяет типы, уникал��ность ID и ссылки групп на существующие классы до передачи данных генератору. Сохранённое расписание хранит и данные школы; для отдельного файла школы используйте кнопку сохранения данных.

## Проверки

```bash
python -m unittest discover -s tests -v
python scripts/run_sample.py
```

Для SQLite-сценария потребуется SQLAlchemy из `requirements.txt`:


## Ограничения

Это исследовательский прототип, не готовая система для официального расписания. В модели пока не реализованы смены, деление класса на одновременные подгруппы, все санитарные нормы и пожелания учителей. Проверка конфликтов ограничена закодированными правилами Python-модели. Алгоритм эвристический и не гарантирует оптимум или поиск допустимого решения за заданное время. Сохранение расписания в JSON не заменяет проверку ответственным сотрудником.

На Fedora в текущем рабочем окружении выявлялся сбой финализации PySide6 при включённом циклическом GC; GUI временно отключает автоматический циклический сборщик мусора. Это обходной путь, а не устранение первопричины в Qt/Shiboken.
