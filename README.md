# School Scheduler — рабочий прототип

Десктопный прототип на Python: генетический алгоритм + локальный поиск, GUI на PySide6 и импортируемые JSON-данные школы.

## Установка и запуск

- Python 3.11+
- `python -m pip install -r requirements.txt`
- `python -m app.main`

На Linux требуется графическая сессия. На Fedora workaround для подтверждённого сбоя циклического GC в PySide/Shiboken: GUI временно отключает автоматический циклический сборщик мусора. Это обходной путь, не устранение первопричины.

## Возможности прототипа

- Генерация расписания на введённых данных школы; прогресс отображается в фоне, поиск можно остановить.
- Импорт и сохранение данных школы в JSON (кнопки «Открыть данные школы» / «Сохранить данные школы»).
- Ручное перемещение урока: двойной щелчок по ячейке, выбор урока и перенос в этот слот. Занятый слот приводит к обмену при наличии в нём одного урока; изменение, увеличивающее число жёстких конфликтов, требует подтверждения.
- Сохранение расписания в JSON вместе с определением школы и повторное открытие этого файла. Поэтому файл можно переносить на другой компьютер и открывать без заранее импортированного набора данных.
- Светлая тема и цвета предметов; одинаковые предметы используют одинаковый цвет.
- Схема пользовательских данных показана в [`examples/school_data.json`](examples/school_data.json).

## Формат файла школы

Корневые поля: `format` (`school-scheduler-school`), `version` (1), `school_name`, `days_per_week` (1–7), `classes` и `groups`. Класс задаётся `id`, `name`, `grade` (1–12). Учебная группа задаётся уникальным `id`, ссылкой `class_id`, `subject`, `teacher_id`, `hours_per_week` (1–60), необязательным `cabinet_id` и логическими признаками `is_physical_education`, `is_heavy_subject`. Одинаковый `teacher_id` указывает на одного учителя в разных группах, это нужно для выявления конфликтов.

Файл можно скопировать из примера, изменить в текстовом редакторе и открыть в GUI. Загрузчик проверяет структуру, типы, уникальность ID и ссылки до запуска алгоритма.

## Проверки

```bash
python -m unittest discover -s tests -v
python scripts/run_sample.py
```

## Границы прототипа

Не реализованы смены, одновременные подгруппы, полный набор санитарных норм, пожелания учителей и типы/доступность кабинетов. Конфликты проверяются только правилами, закодированными в Python reference-модели. Алгоритм эвристический и не доказывает оптимальность. Перед реальным применением расписание требует проверки ответственным специалистом.
