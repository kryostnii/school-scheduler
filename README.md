# School Scheduler - Гибридный алгоритм составления расписания

Школьное расписание - это сложная комбинаторная задача оптимизации, решаемая с использованием гибридного подхода (генетический алгоритм + бэктрекинг).

## Особенности проекта

- **Гибридный алгоритм**: Комбинация генетического алгоритма для глобального поиска и бэктрекинга для локальной оптимизации
- **Четкое разделение ограничений**: Жесткие (не нарушаются) и мягкие (с штрафами) ограничения
- **Математическая модель**: Полная формализация задачи оптимизации
- **Рабочий GUI**: Простой интерфейс для демонстрации работы алгоритма

## Запуск

### Тестирование из консоли:
```bash
python3 scripts/run_sample.py
```

### Запуск с графическим интерфейсом:
```bash
# Установка зависимостей GUI (если отсутствуют)
chmod +x install_gui.sh
./install_gui.sh

# Запуск приложения
python3 app/main.py
```

## Математическая модель

Решение задачи основано на:
1. Жестких ограничениях (конфликты учителей, кабинетов)
2. Мягких ограничениях со штрафами ( СанПиН, окна, предпочтения)
3. Функции приспособленности с раздельным весом ограничений
4. Гибридном подходе: ГА + Бэктрекинг

## Ограничения

- Жесткие ограничения не могут быть нарушены
- Мягкие ограничения оцениваются по штрафам 
- Все уроки должны быть распределены в течение учебной недели
- Соблюдение требований СанПиН (например, 1 класс только I смене)

## Используемые технологии

- Python 3.8+
- PySide6 для GUI
- Стандартные модули Python (typing, dataclasses)
