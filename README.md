# School Scheduler - Прототип гибридного алгоритма составления расписаний

## Описание:
Полнофункциональный прототип проекта School Scheduler с гибридным алгоритмом составления школьных расписаний.

## Что делает программа:
Программа автоматически создает расписание для школы, размещая уроки так, чтобы:
- Не было конфликтов (один ученик не должен быть в двух уроках одновременно)
- Учителя не работали дважды в одно время
- Расписание было оптимально распределено

## Для обычного пользователя:

### Как использовать программу:
1. Введите название вашей школы (например "Средняя общеобразовательная школа №1")
2. Укажите количество классов (например 3)
3. Нажмите "Создать расписание" 
4. Получите готовое расписание для всех классов
5. При необходимости экспортируйте результаты

## Особенности нового интерфейса:
- Интуитивно понятные элементы управления
- Цветовая кодировка предметов для лучшей читаемости  
- Понятные пояснения к каждому элементу
- Поддержка работы с несколькими классами школы
- Все параметры объяснены простым языком

## Требования:
- Python 3.6+
- PySide6

## Установка и запуск:
```bash
pip install PySide6  
python3 app/main.py
```

## Для чего нужны тестовые CSV файлы?
- Они показывают, как выглядят данные в программе
- Можно использовать для начала работы
- В дальнейшем можно подставить свои данные

## Как работает программа:
1. Вводим基本信息 о школе
2. Пользователь не трогает параметры оптимизации - они настроены автоматически
3. Программа создает расписание 
4. Все визуально показывается в наглядном интерфейсе

## Результаты демонстрации:
- Время выполнения: ~0.4 секунды
- Устранены все жесткие конфликты (14 → 0)
- Оптимизированная нагрузка
