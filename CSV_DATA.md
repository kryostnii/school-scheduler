# Тестовые данные для School Scheduler

## Описание:
Файл описания структуры данных в формате CSV, используемый в системе гибридного алгоритма составления школьных расписаний.

## Для обычного пользователя:

### Что такое файлы и зачем они нужны?
- **groups.csv** - информация о классах и предметах
- **schedule.csv** - расписание уроков для каждого дня

### Как использовать:
1. Сначала загрузите эти файлы в программу
2. Программа автоматически создаст расписание для всех классов
3. Можно экспортировать результаты

## Подробное описание файлов:

### groups.csv - информация о подгруппах и предметах
```
id,class_id,grade,teacher_id,hours_per_week,is_physical_education,is_heavy_subject
1,101,5,1,5,False,True
2,101,5,2,4,False,True
3,101,5,3,2,True,False
```

### Пояснение к полям:
- `id` - уникальный номер подгруппы (например 1)
- `class_id` - номер класса (например 101 = 5А)  
- `grade` - уровень сложности/класс (например 5)
- `teacher_id` - номер учителя (например 1)
- `hours_per_week` - сколько часов уроков в неделю (например 5)
- `is_physical_education` - физкультура? (True/False) 
- `is_heavy_subject` - тяжелый предмет? (True/False)

### schedule.csv - расписание уроков
```
day,lesson_number,class_id,subject_id,teacher_id
1,1,101,1,1
1,2,101,2,2
```

### Пояснение к полям:
- `day` - день недели (1-7: понедельник-воскресенье)
- `lesson_number` - номер урока в день (1-10)
- `class_id` - номер класса (например 101 = 5А)
- `subject_id` - номер предмета (1=Математика, 2=Русский язык и т.д.)
- `teacher_id` - номер учителя

## Примеры:

### Структура для 5А класса:
```
id,class_id,grade,teacher_id,hours_per_week,is_physical_education,is_heavy_subject
1,101,5,1,5,False,True    # Математика, 5 часов в неделю
2,101,5,2,4,False,True    # Русский язык, 4 часа в неделю  
3,101,5,3,2,True,False    # Физкультура, 2 часа в неделю
```

### Пример расписания:
```
day,lesson_number,class_id,subject_id,teacher_id
1,1,101,1,1      # Понедельник, 1 урок, 5А класс, Математика
1,2,101,2,2      # Понедельник, 2 урок, 5А класс, Русский язык
```

## Как загрузить данные:
1. Нажмите кнопку "Загрузить" в интерфейсе
2. Выберите файлы groups.csv и schedule.csv  
3. Нажмите "Открыть"
4. Программа автоматически обработает данные

## Важно:
Если вы не знаете, какие у вас классы или предметы, можно использовать тестовые файлы (test_groups.csv, test_schedule.csv)
